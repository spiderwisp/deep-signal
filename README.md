# Deep Signal

An underwater exploration and recovery game for the [Framework Gaming Console (FGC)](https://github.com/spiderwisp/fgc-console), built with Godot. Play with a keyboard or gamepad.

## Windows

1. [Download Deep Signal for Windows](https://github.com/spiderwisp/deep-signal/releases/latest/download/DeepSignal-Windows.zip).
2. Right-click the ZIP and choose **Extract All**.
3. Open the extracted folder and double-click **Deep Signal.exe**.

No installer, Docker, or Godot installation is needed.

## Linux

Use a 64-bit x86 Linux desktop with graphics drivers installed.

1. [Download Deep Signal for Linux](https://github.com/spiderwisp/deep-signal/releases/latest/download/DeepSignal-Linux.tar.gz).
2. Open a terminal in the folder containing the download and run:

   ```sh
   tar -xzf DeepSignal-Linux.tar.gz
   cd DeepSignal-Linux
   chmod +x DeepSignal.x86_64
   ./DeepSignal.x86_64
   ```

After the first launch, you can run **DeepSignal.x86_64** from your file manager if it supports launching executable files. No Docker or Godot installation is needed.

## Graphics and controls

Open **Graphics** from the main menu or pause menu to select **Performance**, **FGC**, or **Ultra**, and adjust fullscreen, V-sync, and the frame limit. Start with **FGC**; use **Performance** if you need a lighter preset. Some preset changes restart the game automatically while preserving your current dive.

Choose **Begin Descent** to play or **Guided Dive** for a guided demo. Open **Controls** for keyboard controls and gamepad button mapping.

All builds are available on the [releases page](https://github.com/spiderwisp/deep-signal/releases/latest).
